# Random Joke Generator

A simple web app that fetches random jokes from the Official Joke API and displays them in a modern UI.

## Features
- Random joke generation from a public external API
- Copy-to-clipboard button
- Responsive layout
- Error handling for API failures

## Run locally
Open `index.html` directly in a browser, or serve it with a local web server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
